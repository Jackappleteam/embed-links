Unfurl

Discord Embed Link Generator

This is a simple app that creates links which Discord shows as a rich embed or a Components V2 layout when pasted. No bot or webhook needed.

Fill in the fields, press Create Link, and paste the link in a Discord message.

Preview

What is Components V2?

Components V2 is Discord's newer layout system for link previews — containers, text, dividers, image galleries and buttons instead of the classic title/description embed. Unfurl builds either kind of link.

Do I need a bot or webhook?

No. The link itself carries the embed data. Discord reads it when the link is pasted, the same way it reads a normal website preview — no bot token, server, or webhook required.

How do I use it?

Fill in the builder or paste JSON, check the live preview on the right, then press Create Link. Paste the generated link into any Discord message to see it unfurl.
